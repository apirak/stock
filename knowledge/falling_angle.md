## บทที่ 1 — Falling Angle คืออะไร

**Falling Angle** (มุมของการร่วง) คือการมองหุ้นที่ราคากำลังลดลง แล้วตั้งคำถามถูกข้อ
แทนที่จะถามว่า "ลงเท่าไหร่" ต้องถามว่า **"ร่วงด้วยมุมไหน — ร่วงเพราะอะไร"**

ราคาที่ร่วงมีสองแบบที่ต่างกันคนละขั้ว:

- **มุมกากบาท (Fallen Angel):** ราคาลงเพราะความกลัว ข่าวระยะสั้น หรือการถอนเงิน
  ของตลาด แต่เครื่องยนต์ธุรกิจยังเดิน — ลูกค้ายังจ่าย ป้อมปราการยังอยู่
  มูลค่าที่แท้จริง (intrinsic value) แทบไม่ขยับ → **โอกาส**
- **มุมตกฟรี (Falling Knife / Value Trap):** ราคาลงเพราะธุรกิจถูกทำลายจริง ๆ —
  เทคโนโลยีเปลี่ยน ลูกค้าย้ายออกถาวร อำนาจตั้งราคาหาย → ส่วนลดคือ
  **ค่าชดเชย ไม่ใช่ของขวัญ**

กติกาทอง: **ห้ามใช้การที่ราคาลงเป็นหลักฐานว่าหุ้นถูก — ต้องหาหลักฐานจากธุรกิจเสมอ**

## บทที่ 2 — เปรียบเทียบราคากับมูลค่าเสมอ (Price vs Intrinsic Value)

สิ่งที่ต้องเทียบคือการเปลี่ยนแปลง "สองด้าน" ไม่ใช่ด้านเดียว:

| ราคา | มูลค่าที่แท้จริง | สรุป |
|---|---|---|
| −15% | −2% | Margin of Safety ดีขึ้นมาก → ผู้เข้าเฝ้าดู (Possible Temporary Mispricing) |
| −30% | −40% | หุ้นนี้แพงขึ้น! → Value Trap Risk |

**Margin of Safety (MoS)** = (Fair Value − ราคาปัจจุบัน) ÷ Fair Value

ช่วงอ่านค่า (แนวทาง ไม่ใช่กฎเหล็ก):

| MoS | ความหมาย |
|---|---|
| < 10% | แทบไม่มีเบาะความปลอดภัย |
| 10–20% | เริ่มน่าสนใจ |
| 20–30% | น่าสนใจ ถ้าธุรกิจดี |
| > 30% | อาจเป็นโอกาสใหญ่ — แต่ต้องหาคำตอบก่อนว่า "ทำไมตลาดลดราคาให้" |

เตือนตัวเอง: ส่วนลด 50% ของธุรกิจที่กำลังพัง แย่กว่าส่วนลด 15% ของธุรกิจเยี่ยมเสมอ

มูลค่าที่แท้จริงเป็น **ช่วง ไม่ใช่ตัวเลขเป๊ะ** — รายงานเป็น Bear / Base / Bull
และทุก FV ที่ยังเป็นค่าประมาณต้องกำกับว่า "proxy" ทุกครั้ง

## บทที่ 3 — วินิจฉัยโรค: แผลชั่วคราว หรืออวัยวะพัง

เมื่อหุ้นร่วงพร้อมข่าวร้าย ให้จำแนกแรงลมกรด (headwinds) ก่อนเสมอ:

### Transitory / Surface-level (แผลผิวหนัง)
ข่าวร้ายชั่วคราว: เหตุการณ์สะเทือนครั้งเดียว, พลาดไตรมาสเดียว, วิกฤตความเชื่อมั่น
— **เหตุผลที่ลูกค้าเลือกใช้ธุรกิจนี้ยังอยู่ครบ**

### Structural Damage (อวัยวะภายในพัง)
เทคโนโลยีถูกแทนที่ถาวร (Kodak/Blackberry), เสียอำนาจตั้งราคา, ลูกค้าย้ายออก
แบบไม่กลับ, ธุรกิจกลายเป็น commodity

**เกณฑ์ตัดสิน (verdict):**
- `Pass - Temporary` — แรงลมกรดชั่วคราว **และ** แหล่งป้อมปราการยังตรวจสอบได้
- `Watch` — หลักฐานปนกัน หรืองบดับตึงตัวแต่รอดได้
- `Fail - Value Trap` — ความเสียหายเชิงโครงสร้าง หรือ leverage บ่งว่าธุรกิจ
  อาจไม่รอดจนถึงวันที่ตลาดเปลี่ยนใจ

## บทที่ 4 — คุณภาพมาก่อนถูก (Quality Before Cheapness)

ถูก + ธุรกิจแย่ ≠ การลงทุนที่ดี ต้องผ่านด่านคุณภาพก่อนคุยเรื่องส่วนลด:

### ป้อมปราการ (Moat) — ต้องระบุแหล่งที่มา ไม่ใช่พูดลอย ๆ
1. **Intangible Assets** — แบรนด์ ใบอนุญาต สิทธิบัตร
2. **Switching Costs** — ลูกค้าย้ายออกแพงกว่าทนอยู่
3. **Network Effect** — ยิ่งคนใช้มาก ยิ่งมีค่า
4. **Cost Advantage** —ต้นทุนต่ำกว่าคู่แข่งจากสเกล/กระบวนการ
5. **Efficient Scale** — ตลาดเล็กเกินกว่าคู่แข่งใหม่จะเข้ามาคุ้ม

ทดสอบ pricing power: ธุรกิจที่ขึ้นราคาทันเงินเฟ้อโดยลูกค้าไม่หนี คือธุรกิจเดียว
ที่กันเงินเฟ้อได้จริง

### เครื่องยนต์ต้องชนะต้นทุนทุน
**ROIC > WACC** ตลอดวงจรธุรกิจ — ถ้า ROIC ต่ำกว่า WACC "การเติบโต" คือการ
ทำลายมูลค่า และ multiple ที่ถูกตาคือกับดัก

## บทที่ 5 — งบดับต้องรอดก่อนกำไรงาม (Balance Sheet Survival)

กำไรบอกว่าธุรกิจเป็นไงตอนอากาศดี — งบดับบอกว่าจะ **รอดพายุไหม**
เกณฑ์ที่ระบบใช้จริง (flag เมื่อเกิน/ต่ำกว่า):

| ตัวชี้วัด | เหลือง (flag) | แดง (เกือบตาย) |
|---|---|---|
| Net Debt / EBITDA | > 3.0x | > 5.0x |
| Interest Coverage (EBIT/ดอกเบี้ย) | < 5.0x | < 2.0x |
| FCF Yield | < 3% หรือติดลบ | FCF ติดลบหนักต่อเนื่อง |
| ROIC vs WACC | ROIC < WACC | — |

ธุรกิจที่ leverage สูงและถูกมาก มักตายก่อนตลาดจะเปลี่ยนใจ —
นี่คือโรงงานผลิต value trap

## บทที่ 6 — Revaluation Discipline (วินัยการประเมินมูลค่าใหม่)

- ราคาขยับทุกวัน = อัปเดต **MoS เท่านั้น** (script ทำได้เอง ไม่ต้องใช้สมอง)
- **ประเมินมูลค่าใหม่ (revalue) เฉพาะเมื่อสมมติฐานเปลี่ยนจริง:** งบการเงิน,
  guidance, โครงสร้าง margin, moat, ส่วนแบ่งตลาด, หนี้, ผู้บริหาร, กฎระเบียบ
- ห้าม rebuild DCF ทุกวันเพราะราคาเด้ง
- ทุกครั้งที่คิดว่าน่าสนใจ ให้วิจัยฝั่งตรงข้ามก่อน: **"ถ้าตลาดถูกและเราผิดล่ะ?"**
  — หา bearish argument ที่แข็งแรงที่สุดก่อนพูดว่า Attractive

## บทที่ 7 — วินัยเข้าซื้อ: 3 ไม้ + เขียนพินัยกรรมก่อนแต่งงาน

1. แบ่งซื้อ **3 ไม้** — ไม้แรก 25–30% ของ position เป้าหมาย (ซื้อครั้งเดียวจบ = จับมีด)
2. ก่อนไม้แรก ต้องมี: thesis เขียนไว้แล้ว + **invalidation criteria ≥ 3 ข้อ**
   ที่สังเกตได้จริงและเจาะจง (เช่น "gross margin ลดลง 2 ไตรมาสติด",
   "ลูกค้ารายใหญ่ประกาศยกเลิก", "coverage หลุด < 3x")
3. เมื่อสัญญาณ invalidation เกิดจริง → ตัด อย่าเฉลี่ยลงนอกแผน
4. Position cap ต่อตัว 5–8% ของพอร์ต (ความผิดพลาดต้องไม่ลบพอร์ตทิ้ง)

ระบบนี้เป็น **ระบบวิจัย ไม่ใช่ผู้จัดการพอร์ตอัตโนมัติ** — บอกได้ว่า
"High Conviction / Attractive / Watch" แต่ **ห้ามพูดว่า "ซื้อเลย"**
การตัดสินใจสุดท้ายเป็นของเจ้าของพอร์ตเสมอ

## บทที่ 8 — กรณีศึกษาประจำห้องสมุด

- **AmEx 1963 (Salad Oil Crisis):** หุ้นลง ~50% จากเรื่องฉ้อโกงที่บริษัทลูก
  แต่คนยังจิปายคาร์ดเหมือนเดิม — ป้อมปราการ (แบรนด์ + เครือข่ายร้านค้า) ไม่โดนแตะ
  Buffett ซื้อ ~40% ของบริษัท → แยก "บริษัทถูกหนี้เรื่องเดียว" ออกจาก
  "บริษัทเสียลูกค้า"
- **Chipotle 2015 (E. Coli):** ราคาเฮือกครึ่ง แต่ economics ระดับร้านไม่พัง
  ลูกค้ากลับมาใน 2–3 เดือน ไม่มีหนี้ → fallen angel แท้
- **Meta 2022:** −75% จากแผง capex + TikTok panic — ตลาด over-discount
  เครื่องยนต์โฆษณาที่ยังเก็บ network effect → แม้คำถามเชิงโครงสร้างจะจริง
  ก็อาจถูกหักบัญชีเกินจริง
- **Kodak / Blackberry:** สัญญาณเชิงโครงสร้างจริง — เทคโนโลยีถูกแทนที่
  ลูกค้าหนีถาวร → ส่วนลดคือค่าชดเชย ไม่ใช่ของขวัญ

5. [ ] MoS อยู่โซนไหน (Base case)?
6. [ ] Portfolio fit — ซื้อเพิ่มแล้วถี่ถ้วนไหม (concentration, sector/country)
7. [ ] Invalidation criteria เขียนได้จริงไหม (≥ 3 ข้อ)?
